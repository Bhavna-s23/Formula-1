Formula 1 Race Intelligence – Web Integration

Project Overview
A Flask-based web application that integrates the Formula 1 Race Intelligence Dashboard and Data Story published on Tableau Public.

Project Features
- F1-themed responsive homepage.
- Project overview and KPI summary.
- Interactive Tableau Dashboard.
- Embedded Formula 1 Data Story with nine scenes.

Technologies Used
- Python
- Flask
- HTML5
- CSS3
- Tableau Public
- Visual Studio Code

Project Structure

Craftivo/
├── assets/
├── Forms/
├── templates/
│   └── index.html
├── app.py
└── README.md


How to Run the Application

1. Open the project folder in Visual Studio Code.
2. Install Flask:
   `python -m pip install flask`
3. Run the application:
   `python app.py`
4. Open `http://127.0.0.1:5000` in your browser.

Outcome
Successfully integrated the published Formula 1 Dashboard and Story into a locally running Flask web application.
